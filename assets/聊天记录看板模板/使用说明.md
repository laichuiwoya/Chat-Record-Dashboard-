# 聊天记录看板模板

复制整个文件夹。填好同目录的 `data.js`，用浏览器打开 `index.html`。空数据文件可直接打开查看模板结构。原始微信导出需先整理成下面的三张表，也可以把导出文件交给 Codex，要求使用 `$chat-record-dashboard` 生成看板。

## 数据格式

`data.js` 的内容为 `window.chatDashboardData = { reportDate, contacts, messages, feedback };`。三个数组的行结构如下。

| 数组 | 每行示例 | 整理规则 |
| --- | --- | --- |
| `contacts` | `{"name":"示例联系人","company":"示例公司","industry":"制造业（推断）","source":"联系人备注","status":"已确认","basis":"备注明确写有公司名，行业据此推断"}` | 一人一行，`name` 在本批数据中唯一，重名用稳定别名区分。统一同一公司的写法。缺失公司或行业填“待确认”。`status` 只表示公司归属，取“已确认”或“待确认”。保留行业推断标记和依据。 |
| `messages` | `{"name":"示例联系人","date":"2026-11-10","time":"09:30","count":1}` | 只录客户侧实际发言，排除己方和系统消息。按来源消息标识去重后每条填 1。若使用聚合行，`count` 填正整数，同一联系人同一天的聚合行使用该组最后一次发言时间。 |
| `feedback` | `{"customer":"示例联系人","date":"2026-11-10","time":"09:30","topic":"功能体验","sentiment":"负面","summary":"导出按钮难找","description":"客户反馈导出入口难找，希望更明显。"}` | 一行一项可独立理解的体验反馈。多条消息讨论同一反馈时合并，彼此独立的问题分开，引用的内容与聊天证据一致。普通沟通计入消息，只有提取出具体体验才写入反馈。 |

日期使用上海本地时间，格式 `YYYY-MM-DD`，时间统一为 `HH:mm` 或统一为 `HH:mm:ss`。消息和反馈都通过联系人名连接到 `contacts`。反馈主题只选功能体验、操作易用、运行性能、产品稳定中的一个。情绪取正面、中性、负面、情绪无法判断。未提取到反馈时，页面显示“暂无体验反馈”。

`reportDate` 可填明确的统计截止日。默认用消息与反馈中最晚的日期，空数据用上海当天。当天、近 7 天、近 30 天均包含截止日，全部从截止日前最早的记录起算。各页面的统计均截至该日。“今天”对应看板统计截止日。

## 体验总览

先按当天、近 7 天、近 30 天或全部筛日期，再按所选主题筛反馈。默认近 30 天、全部主题。下表中的当前反馈指同时满足两个筛选条件的事项。

| 模块 | 功能及口径 |
| --- | --- |
| 本期反馈总结 | 从当前反馈生成简报。首段列条数及反馈最多的主题，保留并列。负面段列负面最多的主题及最多两项摘要，可下钻到全部当前负面反馈。正面段列涉及主题及最多两项摘要，可下钻到当前正面反馈。无负面或无反馈时分别显示对应提示。 |
| 反馈总数 | 当前反馈的事项数，包括情绪无法判断。 |
| 反馈客户 | 有当前反馈的联系人所对应的已确认公司数，同一公司只计一次。该卡下钻只含已确认公司。 |
| 正面、中性、负面 | 分别按情绪计事项数。百分比为该类事项数 ÷ 当前全部反馈数 × 100%，四舍五入到整数。无反馈显示空态提示。 |
| 反馈情绪趋势 | 正面、中性、负面分别按日统计并绘制折线，共用反馈条数纵轴。可查看每日各情绪条数，点击日期打开该日明细。 |
| 体验主题分布 | 四个主题分别计当前反馈条数。条长为主题条数 ÷ 当前反馈总数，零条时条长为零。点击打开该主题明细。 |
| 最近的客户声音 | 按反馈时间倒序展示前五项，显示联系人、摘要、主题、情绪、时间。点击一行查看该联系人在当前范围的反馈。“查看全部反馈”打开完整清单。 |
| 联系人反馈卡与明细 | 每位联系人一张等高卡片，显示公司、反馈条数及当前范围最新的一条评价。点击后展示该联系人的完整反馈和情绪计数。抽屉顶部仍按已确认公司去重统计。负面事项支持待查看、已查看、已处理三态，默认待查看，刷新重置。 |

## 客户活跃度

默认一周。统计单位为已确认公司。发言天数为公司内所有已确认联系人在所选期间的发言日期并集大小，客户消息为这些联系人的 `count` 之和，最近发言取最大时间戳。公司反馈为这些联系人同期反馈的集合。

| 模块 | 功能及口径 |
| --- | --- |
| 客户总数 | 联系人表中已确认公司去重数，含所选期内零发言的公司。 |
| 活跃客户 | 所选期内发言天数至少为 1 的公司数。 |
| 有体验反馈 | 所选期内至少有一项体验反馈的公司数，含情绪无法判断的事项。 |
| 负面涉及客户 | 所选期内至少有一项负面反馈的公司数。 |
| 活跃等级 | 当天分活跃和未活跃。7 天窗口高 4–7 天、中 2–3 天、低 1 天。30 天窗口和全部高 ≥12 天、中 4–11 天、低 1–3 天。所有窗口 0 天为未活跃。 |
| 公司列表与筛选 | 先按发言天数降序，再按消息量降序。按活跃等级、是否含所选情绪或是否没有反馈筛选。顶部卡片下钻相应公司集合。筛选影响列表，卡片显示整个所选期间的公司统计。 |
| 公司详情 | 展示公司活跃等级、发言天数、消息总数、已确认联系人及其各自发言天数、公司情绪分布和同期反馈明细。 |

## 客户分类

覆盖联系人表全量档案。情绪与明细按联系人汇总截至统计日的全部反馈，可用自定义日期筛选情绪和明细，联系人档案和分类统计覆盖全部档案。

| 模块 | 功能及口径 |
| --- | --- |
| 客户总数 | 已确认公司去重数。点击按公司展开联系人。 |
| 联系人数 | 联系人表行数，包含公司归属待确认者。 |
| 已识别行业 | 除“待确认”外的去重行业标签数，包含标为推断的行业。点击按行业展开联系人。 |
| 待确认信息 | 公司归属状态为“待确认”的联系人数。 |
| 行业标签、搜索和筛选 | 行业标签显示全量档案各行业联系人数。搜索联系人名或公司名，行业和状态条件可同时约束列表。顶部卡片显示全量档案统计。 |
| 联系人详情 | 展示公司、行业、识别来源、证据说明、公司归属状态和该联系人截至统计日的情绪分布及逐项反馈。 |

在体验总览、客户活跃度和客户分类的详情里，可点击情绪标签筛选下方评价。点击“全部”恢复完整列表。标签保留原有分布计数，明细标题显示当前筛选结果数。

三个页面均可选自定义开始、结束日期，包含首尾两天，各页独立选择。自定义活跃度沿用“总览”的等级阈值。体验总览超过 90 天时，趋势仅显示有反馈的日期。

## 语音内容

归档含语音时，生成看板前先在本机转写，将文字附回原消息并与前后对话合并分析。语音消息按原发言计一次，相关反馈明细可保留原始转写和语音来源。转写失败的语音标记为未转写。
